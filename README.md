# ⚡ Smart Electricity Monitoring System

## 📌 Description
This project is an ESP32-based real-time electricity monitoring system that tracks current usage, power consumption, and energy units. It also provides a web-based dashboard for visualization and allows setting a daily usage limit.

## 🚀 Features
- Real-time current monitoring using ACS712
- Power and energy (kWh) calculation
- Daily consumption tracking
- User-defined limit alert
- Web dashboard using ESP32
- Bill estimation

## 🛠️ Components Used
- ESP32
- ACS712 Current Sensor
- Bulb (Load)
- WiFi Network

## 🌐 Output
The system hosts a web server and displays:
- Current (A)
- Power (W)
- Energy (kWh)
- Estimated Bill
